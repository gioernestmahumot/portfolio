# Full-Stack AI Developer Portfolio

A minimal, responsive portfolio starter built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Development output is stored in `.next-dev`; production builds use `.next`.
This allows `npm run build` without replacing files used by the dev server.
Restart `npm run dev` after changing the Next.js configuration.

## Customize

Edit `app/page.tsx` to replace:
- Your name / initials
- Email
- GitHub and LinkedIn links
- About section
- Projects
- Technology stack

## Deploy to Vercel

Push this folder to GitHub, import the repository into Vercel, and deploy. No custom server is required for this static portfolio.

## Notes

The current design uses text-based placeholders for technology icons so the starter remains self-contained. Replace these with official SVG assets if desired.
